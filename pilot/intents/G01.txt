Empty-state hint shown when a list is empty unless the user dismissed it this session The page shows a list of notes that starts empty. An "Add note" button appends one note per press; each note has a "Remove" button. While the list is empty, a hint "No notes yet. Add your first note." is shown together with a "Dismiss" button. Pressing "Dismiss" hides the hint for the rest of the session, even if the list later becomes empty again. Do not store the dismissal in persistent storage (localStorage, cookies): when the app is opened again in a new session (a new tab or window; a restart for the PVC runtime) the hint is shown again if the list is empty.
