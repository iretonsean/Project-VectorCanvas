## Checklist items

### L01.1 — Name bold and larger than title  `[A]`

**Operational definition**

- Snapshot at 1280 px. name = visible node whose own text is exactly "Jane Doe"; title = visible node whose own text is exactly "Product Designer".
- Pass iff name.style.font_weight ≥ 600 AND name.style.font_size > title.style.font_size.

**Standardised failure text (the only repair feedback for this item, G2 §4.4):** `Not met: the name must be bold and larger than the job title.`

### L01.2 — Avatar circular, left of name  `[A]`

**Operational definition**

- Snapshot at 1280 px. initials node = visible node with own text "JD"; avatar = its nearest ancestor-or-self that has an opaque own fill (`style.bg` alpha ≥ 0.5) and a roughly square box (|w−h| ≤ 2 px, 16 ≤ w ≤ 160).
- Circular: avatar.style.radius ≥ min(w,h)/2 − 1 (corner radius is clamped to half the shorter side). Left of name: avatar right edge ≤ name left edge + 2 px, and the avatar's vertical extent overlaps the name text box.

**Standardised failure text (the only repair feedback for this item, G2 §4.4):** `Not met: the avatar must be circular and placed to the left of the name.`

### L01.3 — Button spans card width  `[A]`

**Operational definition**

- Snapshot at 1280 px. button = visible node with role `button` whose name matches /connect/i. card = nearest ancestor of the button that has paint (opaque/semi fill, border or shadow) and also contains the name text node.
- Pass iff button.width ≥ 0.80 × card.width AND the left and right gaps between button and card edges differ by ≤ 2 px (full-width, symmetric).

**Standardised failure text (the only repair feedback for this item, G2 §4.4):** `Not met: the Connect button must span the full width of the card.`

### L01.4 — Exact strings present  `[A]`

**Operational definition**

- Snapshot at 1280 px. Each of the five strings "JD", "Jane Doe", "Product Designer", "Building the future of spatial computing via GPU pipelines.", "Connect" must be exactly the own text of at least one visible node (whitespace-collapsed, case-sensitive).

**Standardised failure text (the only repair feedback for this item, G2 §4.4):** `Not met: the exact strings (initials, name, job title, bio, button label) must be present.`
