# L06 — checklist specification (stack-neutral)

**Category:** 1 Layout-heavy  |  **Primary baseline (G2):** B1  |  **Status:** written before any agent output exists.

**G2 intent:** Settings page with grouped sections, each with a title and rows of label + control on the right

Source of truth for the checklist items: `docs/G2_Benchmark_Corpus.md` §5 (main @ 5fdd412). Item order and wording below follow the G2 row. **A** = automatable (decided by the checker from observables), **H** = human-judged: *not judged (D-5)*; pass is decided on A items only.

## Fixture

Sentence(s) to append **verbatim** to the intent text, for **both** stacks (needed so the A items can be evaluated; the G2 intent alone does not contain this data):

> Three groups (for example Account, Notifications, Appearance), each with a heading and at least two rows. Each row has a visible text label on the left and a form control (switch, checkbox, select or text field) on the right whose accessible name is that label text.

## How the checks observe the app

All checks are predicates over the stack-neutral **Snapshot** (`PVC_CHECKER_NEEDS.md` §1) and a small event vocabulary (click, type, key, new session). Baseline: Chromium 141, offline, DOM geometry + Chromium accessibility tree. PVC: `pvc_runtime` headless. Geometry widths: 320, 480, 768, 1024, 1280 px; default height 800; text scale 1 unless stated.

**Locator conventions used by this specimen:**

- controls = visible checkbox, switch, radio, slider, spinbutton, text inputs, combo box, list box
- the row label = the visible text node whose own text equals the control's accessible name
- groups = headings other than the level-1 page title (the level-1 title is ignored when other headings exist)

## Checklist items

### L06.1 — Labels aligned in one column  `[A]`

**Operational definition**

- At 1280 px: ≥ 4 controls, each with a located visible label (conventions) on the same row (vertical overlap) and to the left of its control. Pass iff all labels' left edges are equal within 2 px.

**Standardised failure text (the only repair feedback for this item, G2 §4.4):** `Not met: all row labels must be aligned in one column.`

### L06.2 — Controls right-aligned  `[A]`

**Operational definition**

- At 1280 px, same rows as L06.1. Pass iff all control right edges are equal within 2 px.

**Standardised failure text (the only repair feedback for this item, G2 §4.4):** `Not met: all row controls must be right-aligned.`

### L06.3 — Groups have headings  `[A]`

**Operational definition**

- At 1280 px: group headings = visible `heading` nodes excluding level 1 (if only level-1 headings exist, they count). ≥ 2 group headings. In reading order, every control comes after some group heading, and each group heading is followed (before the next heading) by ≥ 2 controls.

**Standardised failure text (the only repair feedback for this item, G2 §4.4):** `Not met: every group of settings must have a heading.`
