Sentence(s) to append **verbatim** to the intent text, for **both** stacks (needed so the A items can be evaluated; the G2 intent alone does not contain this data):

> The top bar has a search field whose accessible name contains "Search" and an avatar. Each of the four KPI tiles is a visually distinct box (fill, border or shadow) showing a label and one number (for example "1,284", "92%", "$4.2k", "37"). The two panels below the tiles are visually distinct boxes with a title. No external resources are available.

## How the checks observe the app

All checks are predicates over the stack-neutral **Snapshot** (`PVC_CHECKER_NEEDS.md` §1) and a small event vocabulary (click, type, key, new session). Baseline: Chromium 141, offline, DOM geometry + Chromium accessibility tree. PVC: `pvc_runtime` headless. Geometry widths: 320, 480, 768, 1024, 1280 px; default height 800; text scale 1 unless stated.

**Locator conventions used by this specimen:**

- tile value = visible text of ≤ 12 characters that is a number (optional currency prefix, optional %/k/m suffix)
- tile = nearest painted ancestor (fill, border or shadow) of a value that contains exactly one value; outermost only
- panels = outermost painted boxes that start at or below the tiles, area ≥ 20 000 px² and contain text

## Checklist items

### L07.1 — 4 tiles in one row ≥ 1280 px and 2×2 ≤ 768 px  `[A]`

**Operational definition**

- Exactly 4 tiles found (conventions) at every width tested.
- At 1280 px the 4 tile rects form one row (x-disjoint within 2 px, vertically overlapping). At 768, 480 and 320 px the tiles form two rows of two (row shape [2,2]).

**Standardised failure text (the only repair feedback for this item, G2 §4.4):** `Not met: the four KPI tiles must be one row at 1280 px and wider and a 2×2 grid at 768 px and narrower.`

### L07.2 — Search reachable by keyboard  `[A]`

**Operational definition**

- At 1280 px a visible text-input node (`search-field`, `text-field` or `email-field`) with a name matching /search/i exists. Using only Tab presses from the document start it receives focus; typing "abc" with the keyboard makes its `states.value` equal "abc".

**Standardised failure text (the only repair feedback for this item, G2 §4.4):** `Not met: the search field must be reachable and usable by keyboard.`

### L07.3 — Panels equal height  `[A]`

**Operational definition**

- At 1280 px exactly 2 panels found (conventions) and their heights differ by ≤ 2 px.

**Standardised failure text (the only repair feedback for this item, G2 §4.4):** `Not met: the two panels must have equal height.`
