# PILOT_COVERAGE — what the pilot validator covers, and which specimen needs each construct

Scope (Supervisor D-2): the parser, validator and canonical form cover **exactly** what the 15 pilot specimens L01–L10 and G01–G05 need (G2 §5, intents + dev-baseline's fixtures/checklists at `/workspace/dev_work/dev-baseline/checklists/`). No rendering; layout and behaviour *execution* belong to dev-render. "Needs" below means: the hand-written reference program in `pilot-refs/<ID>.pvc` uses it, and I could not express the G2 checklist's A-items without it. It does **not** mean the agent must use it: an agent may find another encoding.

Evidence: every reference validates with **zero diagnostics** and round-trips through canonical form / signing (`pvc-ir/tests/pilot_refs.rs::all_fifteen_refs_validate_clean_and_are_deterministic`); the behaviour of G01–G05 and the structure behind each layout checklist item are asserted in the same file; each new rule has a failing-input test in `pvc-ir/tests/pilot_rules.rs`. Log: `evidence/cargo-test-part2.txt`.

## 3. Deviations from G4 made for the pilot (flagged, not silent)
1. **Row actions are bound-row forms**: `remove item` and `item.field = …` instead of G4 §7.3's `remove-where` / `update-where` predicates. Reason: no ids needed, much less for a 4B model to get wrong. Predicate forms and `sort-by`, `clear` are **not** implemented (no specimen needs them).
2. **Strings use `{name}` holes**, not ICU plural/select (G4 §3). "1 item left / N items left" is two `show`-guarded texts (G02). A plural formatter is a post-pilot item.
3. **`decimal` has a fixed scale of 2** (money, G04). `percent()` is the only rounding operation; its rule is "half away from zero" (equal to half-up for the non-negative amounts in G04).
4. **Breakpoints are two fixed widths** (md ≤ 768 px, sm ≤ 480 px) rather than theme-token breakpoints keyed by arbitrary ranges. They match the widths G2 L02/L04/L07/L09/L10 test (480/768/1024/1280).
5. **`show=`** (A1) is used for conditional presence in addition to `slot`.
6. **`link href`** is an `OpenUrl` action gated by a declared `open-url` capability (one `cap` line per module, prefix match). The G4 text only says "target (an effect `open-url` or a `slot` change)".
7. `layer` is placed by the runtime (centred overlay over the surface); there is no positioning vocabulary.
8. **Checkbox / switch / radio draw state by showing/hiding child shapes** (no conditional paint exists in v0).

## 4. Deliberately NOT covered (each yields a diagnostic with a fix; none is silently accepted)
`image`, `scroll`, `wrap`, `timer`, hover/focus events (`PVC-E-HOVER-ONLY` has no hover event to apply to: unknown event → `PVC-E-SCHEMA` with `choose:press|change|submit`), `storage`/other capabilities in the pilot refs, sort/filter *expressions on `view`* beyond `where=`, `select`/combo-box and `slider` (L06's intent allows a select; the reference uses switches and a text field; an agent that writes `select` gets `PVC-E-UNKNOWN-KIND` with nearest-kind fixes), accordion/disclosure (`expanded` state: L04.2/L09.1 allow stacking instead), gradients/shadows, raw constraints (D-4), ICU plurals, `ext:` kinds, a second locale for the pilot specimens (the strings table supports it; the pilot uses `en`).
Unknown kinds → `PVC-E-UNKNOWN-KIND`; unknown properties → `PVC-E-SCHEMA` with the field list and nearest names; unsupported values → `PVC-E-SCHEMA` with `choose:` alternatives.

## 5. Known gaps in the *validator* (label before quoting any pilot result)
* U4/U5 (320 px, 200 % text) and every geometry-based A-item are **not** validator concerns: dev-render's `pvc-probe` and dev-baseline's checkers judge them. A program can pass `pvc-validate` and still fail U4.
* The contrast rule uses static colours and the nearest filled ancestor; it cannot see a runtime-dependent backdrop and does not check disabled-state or UI-component (non-text) contrast.
* `PVC-W-SLOT-INCOMPLETE` is a warning: an agent may leave a case out on purpose.
* The `{name}`-hole check inspects the strings of **every declared locale**, so a hole missing in `zh-CN` only is reported against that locale's string.
