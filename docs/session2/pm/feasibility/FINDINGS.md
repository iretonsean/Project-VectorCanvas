## Compute arithmetic for the G2 pilot (*inferred* from F18, not measured end-to-end)
- One agent turn ≈ (context tokens ÷ ~100 tok/s prefill) + (output tokens ÷ ~9 tok/s). With a ~4k-token PVC context and ~600 output tokens: ~40 s + ~65 s ≈ 1.75 min uncached (llama-server prefix caching shortens wall time but does **not** change the counted tokens, which G2 counts uncached).
- One specimen × one stack ≤ 6 turns. Categories 1 and 4 run PVC + B1 + B2 (G2 §3.3). The run count is therefore 3 × specimens × arms. These are wall-clock facts for planning compute, not a schedule.
- A 7–8B arm generates at ~0.6× the 4B speed.
